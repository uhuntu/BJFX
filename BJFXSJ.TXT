                        笔迹分析专家系统软件设计说明书

一、软件开发目的：

    借助计算机的速度以及算法程序的“推理”能力，将各种字迹特点所表现出的性格特
征，分类归纳出的性格分析报告，从而实现与人类笔迹分析专家相似的能力。

二、软件实现：

  １、软件依据的主要心理学原理：

    我们知道，字迹表现有多种特点，如字体大小、笔画粗细等，而这些字迹特点分别对
应不同的性格特征。所以，为了更好地对笔迹分析的结果进行集中归纳，进而形成报告，
必须对这些不同的性格特征进行分类。这里应用古希腊的希波克拉底图（如下示），将字
迹特点所表现的性格特征分成四类，分别以DZ、YY、NY、DX标识。

            ┌────────────┬────────────┐
            │心境易波动 悲观的       │       易激惹的 易变的  │
            │焦虑的 性格孤独的    不稳定的    不安好动的 冲动的│
            │僵硬的 不善交际的       │       攻击性的 乐观的  │
            │严肃的 安静的           │       激动的 积极的    │
            │                  ┌──┼──┐                  │
            │                  │抑郁│胆汁│                  │
            │                  │ YY │ DZ │                  │
            ├───内倾────┼──┼──┼────外倾───┤
            │                  │ NY │ DX │                  │

  ２、具体实现办法流程：

    ①由于考虑到方便管理及日后系统的扩充性，决定采用数据库（FOXPRO 2.6）对字迹
    特点及对应性格特征进行管理，库(BJFX.DBF)结构如下：

   ┌───┬───────┬───────┬───────┬───────┐
   │字 段 │选中标记(Xzbj)│气质属性(Qzsx)│字迹特点(Zjtd)│对应性格(Dyxg)│
   ├───┼───────┼───────┼───────┼───────┤
   │类 型 │  逻 辑 型    │  字 符 型    │  字 符 型    │  字 符 型    │
   ├───┼───────┼───────┼───────┼───────┤
   │长 度 │     1        │      2       │     60       │     254      │
   ├───┼───────┼───────┼───────┼───────┤
   │ 内   │初值.F.,选中为│    DZ、YY    │   字迹特点   │ 字迹特点所对 │            
   │ 容   │.T.           │    NY、DX    │              │ 应的性格特征 │
   └───┴───────┴───────┴───────┴───────┘


    ②在软件运行时，用户需对系统所提出的问题逐一细致地进行问答。所提出的问题即
表格中的"字迹特点"栏的内容。用户需依据字迹表现的明显程度按以下四个等级进行回答：
                         N.没有             No;
                         F.模糊             Faded;
                         G.一般             General;
                         O.明显             Obvious.
而后系统将自动对回答进行加权，权数如下：N×0、F×1、G×2、O×4。这里加权的好处
是使明显的字迹特点所表现的性格特征与不明显的拉开距离，进而突出明显的性格特征。
系统设立了四个计数器：DZ、YY、NY、DX，进而根据从问题所对应的记录的"气质属性"字
段中提取出的气质属性标识，往相应的计数器上用回答的权数进行累加。例如：一个问题
所对应的记录的"气质属性"为DZ，回答G，则计数器DZ＝DZ＋2。

　　③系统中设立了四个变量：DZ_C、YY_C、NY_C、DX_C，分别登记库中“气质属性”为
DZ、YY、NY、DX的记录的个数。当用户对所有问题回答完毕后，系统将依据算式有如:DZ=
DZ/DZ_C 对各个计数器进行再加权，从而消除由于库中不同气质属性的记录个数不同而带
来的影响。最后系统将自动从数据库中挑选出"选中标记"为.T.， 并且"气质属性"为统计
权和再加权后的数值最大的计数器的记录，整理出报告。

    说明：本软件所采用的算法的可靠性必须由用户来保证，若用户回答不当，算法的可
靠性将大打折扣。
